# 🎮 Java Tic-Tac-Toe Game

## 📌 About the Project
Java Tic-Tac-Toe is a console-based game developed using Java.
Two players take turns marking spaces on a 3×3 game board.

The first player to align three marks horizontally, vertically,
or diagonally wins the game.

If all cells are filled without a winner, the game ends in a draw.

## 🚀 Features
- Two-player gameplay
- Interactive 3×3 game board
- Turn-based player system
- Win condition detection
- Draw detection
- Console-based interface

## 🛠️ Technologies Used
- Java
- Core Java
- Eclipse IDE

## 🧠 Concepts Used
- Two-dimensional arrays
- Loops
- Conditional statements
- Methods
- User input using Scanner
- Game logic implementation

## 🎯 Project Objective
To strengthen Java programming skills by building
an interactive game using arrays, loops, and conditional logic.
